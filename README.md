# Little feelings

A small feelings check-in, inspired by Inside Out.

- Turn the wheel to find how you feel, then tap the character to capture a moment.
- Write a short story and attach up to four photos.
- Memories roll onto glowing shelves; tap one to open it as a memory orb.
- Everything is saved only in your browser. Use "Download my memories" to keep a backup.

Open `index.html` in a browser to run it. No build step.

Character artwork belongs to Disney/Pixar and is used here for a personal, non-commercial prototype.
